# OVA Universidad Simón Bolívar · Sede Cúcuta

Objeto Virtual de Aprendizaje (OVA) interactivo sobre **Innovación y Design Thinking**, **Ciberseguridad**, **Gestión de Riesgos**, **Cultura Organizacional** y **Gestión del Cambio**.

**Autores:** Alejandro Olivares, Juan Pablo Santamaría y Kevin Aguirre.

## Cómo abrirlo sin instalar nada ni ejecutar comandos

* Descarga el proyecto (o el archivo `docs/index.html`) y haz **doble clic en `index.html`** o en **`docs/index.html`** para abrirlo directamente en tu navegador (Chrome, Edge, Firefox), sin Node.js ni servidores locales.

## Cómo publicarlo en GitHub Pages

En **Settings → Pages** de tu repositorio, cualquiera de las opciones funciona:
* **Source: Deploy from a branch** → rama `main`, carpeta **`/docs`** (o `/ (root)`).
* **Source: GitHub Actions** → despliegue automático mediante `.github/workflows/deploy.yml`.

## Modo desarrollo (opcional)

```bash
npm install
npm run dev
```
